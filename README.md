# 🐾 Augintinio Dienoraštis

Visapusiška „React + Vite“ programa, skirta stebėti augintinio kasdienius poreikius, užduotis bei progresą.

---

## 📌 Apie projektą

**Augintinio Dienoraštis** padeda augintinių šeimininkams lengvai sekti kasdienius priežiūros darbus (maitinimą, pasivaikščiojimus, vaistus, kirpyklą ir kt.). Programa leidžia keisti augintinio vardą, pridėti naujas užduotis, stebėti dienos progresą procentais bei skirstyti užduotis į **Atlikta** ir **Neatlikta**.

---

## 🚀 Technologijos

- **React 18** (Komponentų architektūra, React Hooks: `useState`, `useEffect`)
- **Vite** (Greitas kodo surinkimas ir modulinė plėtra)
- **CSS3** (Custom stiliai, tamsi tema, gradientai)
- **Local Storage** (Būsenos išsaugojimas naršyklėje)
